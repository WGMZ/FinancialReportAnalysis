## 口径与期间可比性约定

- **期间**:`24Q3` 到 `26Q2` 为日历季度的实际值;`26Q3E` 是本报告的预测(紫色/带 E)。**同比**对比 Q3'25,**环比**对比 Q2'26。

- **一次性项目**:JPM 的 Q2'26 含约 $5.4B 的 Visa 一次性收益,在环比比较和 EPS 趋势中单独标出或剔除(图 5 用斜线标出,图 6、图 7 已剔除)。

- **第四季度**:XBRL 不单独披露 Q4,用「全年 − 前三季」推出;因此 EPS 为近似值。

- **收入口径**:总收入 = 净利息收入 + 非息收入(GAAP,不含 FTE 调整)。交易线是损益表里的交易类收入,不含做市相关的净利息收入,因此低于管理层口径的 Markets 收入(例如 JPM Q2 的 Markets $12.1B 对应图中交易线 $9.0B)。

- **颜色**:蓝=净利息收入,橙=投行费用,绿=交易/做市,灰=其他非息,紫=预测;红=负债端或不利,深蓝=资产端。每家银行在所有图里使用同一种颜色。

- **单位**:除注明外为十亿美元($bn);bp = 基点(0.01%);`$M` = 百万美元。

- **估算与披露的区分**:IPO 费用中,招股书披露的标「披露」,其余标「估算」;各行分成按角色加权,是估算,不是银行披露。

## 关键发现速览

- **曲线**:Q3 国债曲线整体上移 32-90bp,5Y 涨幅最大(+90bp),10Y 到 5.29%,2s10s 从 30bp 升到 41bp。政策利率季均只 +4bp,期末 +25bp。(图 1-3)

- **重定价**:每 $1000 亿重定价的资产,按 5Y 利率变动年化多收约 $0.90B;存款成本在 β=40% 下,按季均多付约 $15M、按期末利率多付约 $100M。收入端先到,存款成本后追。(图 4)

- **收入**:JPM -1.1%、BAC -4.8%、C -2.4%、WFC -1.1%、GS -13.8%、MS -3.0% 是 Q3E 总收入相对 Q2'26(JPM 已剔除 Visa)的变化;同比则全部为正(+4.4% 到 +15.5%)。环比下降主要来自交易和 IB。(图 5-6)

- **AFS/HTM**:BAC 的 HTM 未实现损失 $82.1B,WFC $32.4B,JPM $18.2B;这些不进监管资本,但是经济账面价值的隐性损失。(图 10-12)

- **压力测试**:再加息 100bp(平行),含 HTM 经济损失的净影响为 JPM -$14.0B(占 TCE -4.7%)、BAC -$21.3B(占 TCE -10.3%)、C -$7.9B(占 TCE -4.7%)、WFC -$11.4B(占 TCE -8.1%)、GS -$4.6B(占 TCE -4.6%)、MS -$3.5B(占 TCE -4.1%)。BAC 最敏感,几乎全部来自 HTM。(图 13-14)

- **IPO**:我们梳理的 Q3 共 18 单、募资约 $32.6B,估算承销费合计约 $611M,其中 SK hynix 约 $258M;对六大行合计约 $376M,占各行 Q3E 投行费用的 0.5%-6.9%。Q4 的最大变量是 Anthropic(媒体报道,尚无公开 S-1)。(图 15)

## 术语表

| 术语 | 含义 |
|---|---|
| NII / NIM | 净利息收入 / 净息差 |
| AFS / HTM | 可供出售证券(按公允价值入 AOCI)/ 持有至到期证券(按摊余成本,浮亏不入资本) |
| AOCI | 累计其他综合收益,AFS 浮盈浮亏的累计 |
| TCE / TBV | 有形普通股权益 / 有形账面价值 = 权益 − 商誉 − 无形资产 − 优先股 |
| IB / S&T | 投行业务 / 销售与交易 |
| 2s10s | 10 年期减 2 年期国债收益率 |
| 熊陡 / 熊平 | 利率上行且曲线变陡 / 变平 |
| β(存款 beta) | 存款利率变动 ÷ 政策利率变动 |
| 久期 | 利率每变动 1 个百分点,价格近似反向变动的百分比 |
| P/E (TTM) | 股价 ÷ 过去 12 个月 EPS |
